# Альфа-Бизнес

Персональная новостная аналитика: профили из CSV и API команды, публикации ЦБ и пяти отраслевых RSS Ведомостей, девять материалов Альфа-Банка из кейса, разбор и диалог с проверяемыми основаниями. Интерфейс — HTML/CSS/JS; сервер сайта — Node.js; API команды — .NET.

## Запуск

Нужны Node.js **24.22.1+**, .NET SDK **10**, pnpm **11.25.0** и Python **3.12** для ML. Отдельную копию актуальной ветки backend разместить рядом с копией сайта, по умолчанию — в папке Alfa-builders-backend. Перед первым запуском выполнить `npm run setup:ml`: окружение и модель сохраняются вне репозитория. Если окружение Python уже подготовлено, указать его через `ML_PYTHON_EXE`.

Из website/:

```sh
npx pnpm@11.25.0 install --frozen-lockfile
npm start
```

Открыть http://127.0.0.1:4173. Единый запуск собирает API, запускает его на 5194 и сайт на 4173; Ctrl+C останавливает созданные процессы. Уже работающий API используется повторно. C#-исходники не меняются.

BACKEND_PATH задаёт папку бэкенда; BACKEND_PORT и PORT — порты. Демонстрационная SQLite создаётся вне Git отдельно для каждой версии схемы; старые базы сохраняются. Это изоляция демо-данных, не промышленная миграция. Если API запущен отдельно, достаточно npm run dev.

## Настройки

Скопировать .env.example в .env.local и указать LLM_API_KEY. npm start загружает этот файл. Прямой запуск:

```sh
node --env-file=.env.local server.mjs
```

## Источники и обработка

config/sources.json содержит точные разрешённые хосты, RSS ЦБ, пять отраслевых RSS Ведомостей и девять PDF из папки кейса. Поддерживаются RSS/Atom, HTML и PDF. Сборщик выделяет дату, заголовок, текст, ключевые предложения и темы; удаляет активную разметку, отсеивает дубли по URL/хешу. Ведомости используются как короткие анонсы RSS со ссылкой; полная статья и подробности за пределами анонса не предполагаются. Ошибка одного источника не прерывает остальные.

PDF банка оказались сканами. PDF.js рендерит страницы, Tesseract распознаёт русский и английский без отправки PDF во внешний OCR. Модели включены в зафиксированные зависимости; результат содержит страницы, confidence и отметку неполного извлечения. По умолчанию извлекается до 12 страниц, OCR - до 6; тайм-аут 120 секунд. Новый банковский PDF остаётся на проверке даже после OCR. config/bank-excerpts.json хранит короткие цитаты, страницы, даты и SHA-256, проверенные по изображениям; доверие к цитате переносится только при совпадении хеша. Полные PDF и извлечения в Git не входят.

Материалы банка показываются как **исторический контекст**. Среди них есть стальной обзор от 15.04.2021; у золотого обзора известен отчётный месяц август 2026, точная дата публикации неизвестна. Дата не подменяется первым числом месяца. Неподтверждённые A_Nx не используются как банковская экспертиза.

Новые новости классифицируются и ранжируются сервером по тематике и профилю без ручных тегов. Баллы готовых карточек .NET сохраняются. Новые оценки помечены source-rules-v3; это релевантность, не вероятность риска. Устранены лексические совпадения с газированной водой, спортивными ставками и музейными материалами; расширены формулировки затрат на персонал, госзакупок и внешнеторговых ограничений. Ниже 0,4 карточка скрыта.
Неоднозначные старые формулировки про «закупки», направление PMI и цены топлива заменяются адаптером на осторожные пояснения с необходимостью проверки; C# и баллы не меняются.

В «Источниках» доступны состояние загрузок, документы и импорт официальной HTML-статьи с датой. Дополнительные RSS/PDF подключаются конфигурацией. Поиск работает по собранному корпусу; произвольного поиска по интернету нет. Расписание действует только при работающем сервере.

## AI-сценарий

1. Сервер сам загружает профиль и доступную новость.
2. DeepSeek формирует план и выбирает инструменты чтения, банковские материалы и поиск по корпусу.
3. Разбор содержит условные риски, возможности, действия, пробелы и основания каждого вывода.
4. Код проверяет JSON, ссылки, буквальные цитаты и значения признаков. Qwen проверяет смысловую связь, факты и атрибуцию.
5. При замечаниях агент ищет дополнительные материалы и выполняет до двух исправлений. Повторный отказ показывается ошибкой, без подмены готовой заготовкой.
6. Кэш на 6 часов зависит от моделей, версии обработки, компании, события и корпуса. Совпадающие запросы объединяются.

Диалог использует проверенный разбор, текущие источники и до шести пар предыдущих сообщений. Тексты источников и история считаются недоверенными данными. Модель не может исполнять команды, выбирать произвольные URL или менять данные.

Проверка цитат и вторая модель не заменяют независимый фактчекинг и эксперта.

## Интерфейс и качество

На экране `#bank` показана точка входа «Новостная аналитика» из демонстрационной главной Альфа-Бизнес. Она открывает действующую ленту выбранной компании; банковские счета и операции не имитируются.

Общий формат карточки и маршруты команды описаны в [API_CONTRACT.md](API_CONTRACT.md). Интерфейс использует /api/companies, /api/company, /api/feed, /api/chat и /analyze. Чтение ленты не запускает платную генерацию: до неё ai_conclusion=null. Старые маршруты сохранены.

Сервер учитывает отрасли трёх крупнейших получателей/отправителей платежей и наблюдаемый состав группы. Косвенная отраслевая связь сама по себе не поднимает новость в фокус; доля платежей не доказывает зависимость поставок. Позиция ОКВЭД относится к выборке, сумма выручки группы не консолидирована. В модель не отправляются ID контрагентов или строки платежей.

Перепечатки объединяются по URL, близким заголовкам и российскому событию ключевой ставки в пределах 48 часов. Прогноз и решение, страны и даты разделены. Это консервативные правила: произвольные перефразировки могут остаться разными карточками. Балл группы — максимум, тексты и ссылки публикаций сохранены раздельно, прежние ID поддерживают избранное. Разные цифры помечаются для сверки, без автоматического выбора «истины».

Пять демоновостей уточнены в config/prepared-news.json: ссылки, краткое сверенное изложение, короткие оригинальные цитаты и ограничения подтверждения. Исходные XLSX/JSON и C# не переписаны. RSS-анонс, редакционное изложение и извлечённый текст имеют разные подписи.

Мониторинг показывает Precision@5 только для полностью размеченных пятёрок, пересечение лент разных разделов ОКВЭД, P95 выдачи, открытия источников, использование диалога и токены обеих моделей. Счётчик учитывает также обрезанные/отклонённые ответы; тайм-аут может иметь неизвестный расход. Тариф неизвестен — стоимость и остаток не вычисляются. Проверенные цены RUB/миллион токенов задаются LLM_PRICES_RUB_PER_MILLION, локальный предел — LLM_DAILY_BUDGET_RUB. Ограничение провайдера остаётся общим для команды.

Сохранены дизайн, поиск, фильтры, сохранённые карточки, сравнение компаний и экспорт CSV/JSON. В карточке доступны событие, влияние, рекомендации, источники, точные основания и этапы обработки.

Отзывы сохраняются на сервере отдельно для пользователя/компании/новости, могут быть изменены или удалены; комментарии не передаются модели. История чата и сохранённое остаются в браузере. Экспорт включает подготовленный AI-разбор; полные профили и таблицы платежей не выгружаются.

«Качество анализа» показывает контрольные примеры, связь выводов с источниками, исправления, ошибки, отзывы и экспертные оценки. Отсутствие данных не заменяется процентом успеха. Подробности: [QUALITY.md](QUALITY.md).

## Учётные записи

Без AUTH_USERS_FILE сервис слушает loopback и доверяет локальному пользователю компьютера. Для проверки ролей создать папку и файл аккаунтов **вне Git**:

```powershell
# Свой пароль длиной от 12 символов передать через ALFA_NEW_PASSWORD.
node scripts/create-access.mjs ../../private/access.json analyst analyst U_258131
```

Скрипт сохраняет scrypt-хеш, не пароль; существующие аккаунты не перезаписывает. Задать AUTH_USERS_FILE и перезапустить сервер. Не помещать пароль в аргументы или коммит.

Роли: viewer — чтение; analyst — разбор и отзывы; expert — также качество и экспертная оценка; editor — источники и качество; owner — все действия. Поле companies ограничивает ID компаний, ["*"] разрешает все. Проверки выполняются сервером при каждом обращении.

Защита и ограничения прототипа описаны в [ARCHITECTURE.md](ARCHITECTURE.md).

## Оформление

Кнопка «Тема» в верхней панели открывает пять вариантов: Графит, Светлая, Север, Шалфей и Слива. Палитра применяется ко всему интерфейсу, включая фильтры, источники и разбор новости; брендовый знак остаётся красным. Выбор хранится в браузере и применяется до загрузки стилей при следующем открытии.

## Проверка

```sh
npm run check
npm test
```

Тесты изолируют данные, HTTP API и модель; не требуют ключа или интернета. Проверяются парсер, SSRF, цитаты, новые события, адаптация агента, кэш, права, CSRF, отзывы и перезапуск.

data/quality-benchmark.json — переданные 120 синтетических примеров для 16 профилей; data/quality-regression.json — прежние 24. Оба набора использованы для проверки/доработки правил, независимость не заявляется. Запуск: node scripts/evaluate.mjs data/quality-benchmark.json. Проверка CSV: python analytics/test_profiles.py. OCR-тест создаёт собственный скан и проверяет распознанные символы, без сети и ключа.

Ручной сценарий: компания → источники → новая публикация → разбор → точные основания → исторический контекст банка → уточняющий вопрос → другая компания → сравнение → фильтры/экспорт → тестовый отзыв и удаление → качество.

## Известные ограничения версии 0.3.0

Сравнение всего каталога из 115 компаний может загружаться частично: запросы пока отправляются одновременно. Единичная ошибка атомарной замены service.json может приводить к HTTP 500 при чтении ленты, поскольку ответ ожидает запись метрик. Эти сценарии требуют доработки устойчивости.

У общего API есть небольшие расхождения: отсутствие id/company_id и POST /api/feed возвращают 404 вместо 400/405; scenario в списке компаний пока не сопоставлен с demoScenario профиля. Независимая экспертная оценка, Docker и запуск на другом компьютере ещё не подтверждены.

## Docker

compose.yaml объединяет сайт и API; нужен Docker Compose 2.17+. Задать ALFA_ACCESS_FILE — файл аккаунтов вне Git; BACKEND_CONTEXT при необходимости меняет папку NewsAnalytics из копии backend.

```sh
docker compose --env-file .env.local up --build
```

Веб-порт опубликован только на 127.0.0.1:4173; API не опубликован наружу. Ключ передаётся средой, аккаунты — read-only файлом, данные — томами. C#-исходники не меняются. На машине без Docker запуск контейнеров не считается проверенным.

## Файлы и границы

dist/ — интерфейс; server/ — источники, поиск, ранжирование, AI, доступ, качество и хранилище; config/ — публичные источники и проверенные короткие фрагменты; scripts/ — запуск и обслуживание; test/ — тесты. Исходные demo_profiles.json и feed_preview.xlsx сохранены в data/ и напрямую не раздаются.

CSV-сборка обрабатывает весь исходный массив и по умолчанию готовит все 115 компаний с выручкой больше 15 млрд руб.; --ids выбирает произвольные однозначные ID. Один конфликтующий ID в исходнике исключается и фиксируется в статистике, не сливается в выдуманную компанию. Полные входные данные, промежуточные результаты и профили хранятся вне Git. Реальная рыночная доля, независимое экспертное подтверждение и промышленный SSO не заявляются. Подробнее: HANDOFF.md и DEMO.md. Сторонние компоненты перечислены в THIRD_PARTY_NOTICES. Публикация и push выполняются отдельно по запросу.

## Подключённый ML-модуль

Локальный единый запуск включает Python-модуль из ветки ml: Gemma извлекает факты, 25 правил дают дополнительный скоринг, ChromaDB находит проверенные материалы банка, DeepSeek готовит разбор. Сайт сохраняет проверку цитат и Qwen; интерфейс карточек и баллы сервиса данных не меняются. Нужны Python 3.12, зависимости из ml/requirements.txt и ML_PYTHON_EXE. Инструкция: [ml/README.md](ml/README.md). ML_ENABLED=0 явно возвращает прежний Node-режим. Публикация новой интеграции выполняется отдельно.
