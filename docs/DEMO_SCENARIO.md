# Сценарий проверки

Время: 5–7 минут.

1. **Вход.** Главный экран Альфа-Бизнеса, блок «Сегодня важно».
2. **Компания U_9250** — строительство инженерных сооружений, выручка 62 млрд руб., ВЭД с Китаем, кредит и лизинг.
   - Вверху ленты — решение США по санкциям (0,99) и возобновление экспорта дизеля (0,85).
   - Открываем новость про дизель: факты, позиция Альфа-Банка, вывод для компании. Видно, какие признаки компании повлияли на вывод: отрасль и лизинг техники.
   - Предложенный следующий шаг — обсудить условия лизинга.
3. **Переключаемся на U_258064** — оптовая торговля напитками, кредиты, без ВЭД.
   - Лента другая: новости про дизель нет, наверху санкции (из-за зависимости от поставщика) и PMI.
   - Одни и те же новости — разные ленты для разных компаний.
4. **Уточняющий вопрос.** «Как это повлияет на расчёты с поставщиками?» Ответ приходит со ссылками на источники.
5. **Этапы обработки.** Во вкладке «Источники» карточки показываем, какие шаги сделал агент и на какие основания опирается каждый вывод.
6. **Новая новость.** Открываем свежую публикацию Банка России, которой не было при подготовке, и показываем разбор в реальном времени.

Если модель недоступна во время показа, используем сохранённые разборы из базы.
