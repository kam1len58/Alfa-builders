# Альфа-Будущее: Бэкенд новостной аналитики и персонализированных инсайтов

Интеллектуальный бэкенд-сервис на .NET 10 для автоматического сопоставления внешних новостей, аналитики Альфа-Банка и детального бизнес-контекста крупных корпоративных клиентов.

## Запуск
Для запуска проекта требуется установленный **.NET 10 SDK**.

```bash
# Перейти в директорию проекта
cd NewsAnalytics

# Запуск бэкенд-сервера
dotnet run --project NewsAnalytics
```

После запуска сервис доступен локально. Интерактивная документация и тестирование API через Swagger UI открываются по адресу:

http://localhost:5194/swagger (порт может отличаться в зависимости от конфигурации окружения).

## Конфигурация LLM
Параметры подключения к языковой модели (Endpoint, ApiKey, Model) задаются в `appsettings.json` в секции `Llm`. Ключ должен храниться только локально и не коммититься в публичные репозитории. При недоступности LLM (ошибки сети, некорректный ключ, таймаут, невалидный JSON-ответ) сервис автоматически переключается на rule-based fallback, поэтому API всегда возвращает корректный разбор.

## API
Сервис предоставляет три основных эндпоинта:

- **`GET /api/companies`** — список корпоративных профилей из `demo_profiles.json`.
- **`GET /api/companies/{id}/feed`** — персональная лента новостей для компании `{id}`. Каждая новость содержит оценку релевантности (`score`), уровень приоритета (`tier`: Focus / All / Hidden), список сработавших правил (`hits`) с объяснениями и рекомендуемыми банковскими продуктами, позицию Альфа-Банка (`alfaBankPosition`) и расширенные поля: `whyImportant`, `consequences`, `actions`, `sources`.
- **`GET /api/newsinterpretation/{companyId}/news/{newsId}`** — полный персональный разбор одной новости: риски, возможности, рекомендуемые действия, позиция банка и подробный лог работы агента в поле `analysisSteps`.

Swagger UI автоматически генерирует OpenAPI-спецификацию по всем контроллерам и позволяет тестировать эндпоинты прямо из браузера.

## Агентный пайплайн
Разбор новости выполняется агентом из 6 последовательных шагов, каждый из которых логируется в `analysisSteps` ответа:

1. Загрузка профиля компании и новости.
2. Автоматическая классификация новости по тегам и правилам.
3. Скоринг релевантности с динамическими объяснениями (учитывающими направление события — рост или снижение показателя).
4. Загрузка экспертной позиции Альфа-Банка.
5. Генерация персонального разбора через LLM (с автоматическим fallback на правила при сбоях).
6. Самопроверка полноты и непротиворечивости результата.

Пайплайн обеспечивает полную трассируемость: по `analysisSteps` всегда видно, какой путь прошёл разбор и на каком шаге сработал fallback.

## Интеграция с фронтендом
Сервис настроен с политикой CORS, допускающей запросы с локальных адресов разработки (`localhost`), что позволяет фронтенду (React/Vue/Angular на портах 3000/5173/4200) напрямую обращаться к API без прокси.

## Файлы и структура
- `NewsAnalytics/` — основной проект ASP.NET Core Web API (контроллеры, точка входа Program.cs).
- `NewsAnalytics.DAL/` — слой доступа к данным: Entity Framework Core, контекст базы данных AppDbContext, репозитории и DTO.
- `NewsAnalytics.BLL/` — бизнес-логика: движок скоринга (NewsScorer), сервисы ленты, агентный пайплайн (NewsAnalysisAgent) и интеграция с LLM.
- `demo_profiles.json` — исходные профили корпоративных клиентов (выручка, ОКВЭД, регионы, признаки бизнеса).
- `golden_news.json` — эталонный набор новостей с тегами, правилами и экспертной позицией Альфа-Банка (alfa_view).
- `news_analytics.db` — локальная база данных SQLite (создаётся и заполняется автоматически при первом запуске).
- `Dockerfile` — multi-stage конфигурация для сборки контейнера (build → publish → final на базе ASP.NET runtime 10.0).

## Инициализация и обновление данных
При старте приложения срабатывает автоматический сидер (DbInitializer), который наполняет базу данных из файлов в корне проекта:

- Загружает и валидирует профили компаний из demo_profiles.json.
- Индексирует глобальную базу новостей из golden_news.json.
- Автоматически извлекает экспертные позиции Альфа-Банка из поля alfa_view файла golden_news.json и заполняет таблицу макроаналитики AlfaAnalytics.

Примечание: Для полного сброса и перезаполнения базы данных достаточно удалить файл news_analytics.db и перезапустить приложение.

## Состав репозитория
Коммитить исходный код бэкенда, конфигурационные файлы, исходные датасеты (demo_profiles.json, golden_news.json), README.md, Docker-конфигурацию и лицензии. Временные файлы сборки (bin/, obj/), локальные базы данных (*.db) и пользовательские файлы окружения в репозиторий не включаются.
