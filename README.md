# Альфа-Бизнес

Веб-сервис персональной новостной аналитики для компаний. Эта ветка содержит сайт в `website/`; API на .NET находится в отдельной ветке `backend`.

Сайт получает компании, новости, оценки и объяснения из API. Доступны поиск и фильтры, сохранённые карточки, сравнение новости у разных компаний, экспорт CSV/JSON и локальная обратная связь. По запросу модель готовит персональный разбор и отвечает на вопросы по событию.

## Запуск

Нужны Node.js 20.6+, .NET SDK 10 и доступ к репозиторию. Для первого запуска можно получить обе ветки в отдельные папки:

```sh
git clone --branch Damir-website --single-branch https://github.com/kam1len58/Alfa-builders.git Alfa-builders-website
git clone --branch backend --single-branch https://github.com/kam1len58/Alfa-builders.git Alfa-builders-backend
```

1. В PowerShell из папки `Alfa-builders-backend` запустить API:

```powershell
$env:ASPNETCORE_ENVIRONMENT = 'Development'
dotnet run --project NewsAnalytics/NewsAnalytics/NewsAnalytics.API.csproj --no-launch-profile --urls http://127.0.0.1:5194
```

2. Во втором терминале из папки `Alfa-builders-website/website` запустить сайт:

```sh
npm run dev
```

Открыть [http://127.0.0.1:4173](http://127.0.0.1:4173). Установка JavaScript-зависимостей и сборка не нужны. Без ключа модели работают лента и инструменты интерфейса; для персонального разбора и диалога нужен следующий шаг.

3. Для подключения модели остановить только сервер сайта, скопировать шаблон в PowerShell:

```powershell
Copy-Item .env.example .env.local
```

Вписать ключ в `LLM_API_KEY` файла `.env.local`, затем запустить сайт:

```sh
node --env-file=.env.local server.mjs
```

Ключ в репозиторий не включён. `.env.local` игнорируется Git; в браузер ключ не передаётся. По умолчанию используется API организаторов и модель `deepseek/deepseek-v4.1-flash`.

## Проверка и документация

Из `website/` выполнить `npm run check` для проверки синтаксиса JavaScript. Настройка адреса API, описание файлов, методов модели и ручных проверок приведены в [website/README.md](website/README.md).

Текущая версия рассчитана на локальный запуск. Новости поступают из подготовленного набора бэкенда; внешний поиск ещё не подключён. Выводы модели отделены от исходных новостей и не заменяют проверку фактов. Неподтверждённые банковские комментарии не выдаются за официальную позицию банка.

Исходные XLSX/JSON находятся в `website/data/`; сервер их напрямую не раздаёт. Локальные ключи, базы, кэш, журналы и служебные материалы в Git не включаются.
