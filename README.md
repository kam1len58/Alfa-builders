# Новостная аналитика для руководителей крупного бизнеса

Сервис для интернет-банка Альфа-Бизнес. Он отбирает новости, важные для конкретной компании, и объясняет, как событие может повлиять на её бизнес. В разборе отдельно показаны факты из источника, позиция Альфа-Банка и выводы модели, у каждого вывода есть основание.

Решение подготовлено для хакатона Альфа-Банка, трек «Новостная аналитика для принятия бизнес-решений».

## Как это работает

1. **Профиль компании.** Из данных кейса строится профиль: отрасль, выручка, место в отрасли, продукты банка, ВЭД, ключевые поставщики и покупатели, связанные компании.
2. **Новости.** В корпус попадают подготовленные разборы и свежие публикации из официального RSS Банка России.
3. **Отбор.** Бизнес-матрица из 25 правил определяет, кому и насколько важна новость: сохранение высокой ставки важно компании с кредитами, рост цен на дизель — строительной или транспортной.
4. **Разбор.** Агент планирует шаги, читает профиль, новость и материалы Альфа-Банка, готовит разбор и проверяет его второй моделью. Если проверка находит проблемы, агент ищет дополнительные материалы и исправляет ответ.
5. **Диалог.** Пользователь задаёт уточняющий вопрос по новости и получает ответ с основаниями.

## Структура репозитория

```
website/       интерфейс Альфа-Бизнеса и сервер на Node.js: сбор источников, AI-разбор, диалог
NewsAnalytics/ API на .NET 10: компании, лента, скоринг, разбор новости
analytics/     скрипты на Python: профили компаний, бизнес-матрица, оценка новостей
data/          профили компаний, бизнес-матрица, эталонные разборы, превью ленты
docs/          описание данных и сценарий демонстрации
```

## Запуск

Нужны Node.js 24.22.1+, .NET SDK 10 и pnpm 11.25.0.

```bash
cd website
npx pnpm@11.25.0 install --frozen-lockfile
cp .env.example .env.local        # указать LLM_API_KEY
BACKEND_PATH=.. npm start
```

Сайт: http://127.0.0.1:4173. Команда собирает и запускает API (порт 5194) и сайт. Без ключа работают лента, источники и инструменты интерфейса; разбор и диалог требуют ключ.

Через Docker:

```bash
cd website
BACKEND_CONTEXT=../NewsAnalytics ALFA_ACCESS_FILE=<путь к файлу аккаунтов> docker compose up --build
```

Файл аккаунтов создаётся вне репозитория, см. [website/README.md](website/README.md#учётные-записи).

## Языковые модели

Используются модели из списка, разрешённого кейсом, через API организаторов:
- `deepseek/deepseek-v4.1-flash` — планирование и генерация разбора;
- `qwen/qwen3.6-35b-a3b` — смысловая проверка.

Ключ хранится только в переменных окружения и в репозиторий не попадает. Ответы кэшируются, чтобы укладываться в дневной лимит.
