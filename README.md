# Новостная аналитика для руководителей крупного бизнеса

Сервис для интернет-банка Альфа-Бизнес. Он отбирает новости, которые важны для конкретной компании, и объясняет, как событие может повлиять на её бизнес. В объяснении отдельно показаны факты, позиция Альфа-Банка и вывод модели.

Решение подготовлено для хакатона Альфа-Банка, трек «Новостная аналитика для принятия бизнес-решений».

## Как это работает

1. Из данных банка строится профиль компании: отрасль, выручка, продукты банка, внешнеэкономическая деятельность, ключевые поставщики и покупатели, связанные компании.
2. Сервис собирает свежие новости из открытых источников.
3. Бизнес-матрица определяет, кому и насколько важна новость: например, сохранение ключевой ставки важно компании с кредитами, рост цен на дизель — транспортной или строительной.
4. ML-агент готовит разбор: что произошло, почему это важно именно этой компании, какие риски и возможности, что можно сделать, как событие оценивает Альфа-Банк. У каждого вывода есть источник.
5. Пользователь может задать уточняющий вопрос по новости.

## Структура репозитория

```
analytics/   профили компаний, бизнес-матрица, оценка новостей (Python)
backend/     API, сбор новостей, база данных
ml/          агент, поиск по материалам Альфа-Банка, работа с LLM
frontend/    интерфейс Альфа-Бизнеса
data/        профили компаний, матрица, эталонные разборы
docs/        документация
```

## Требования

- Docker и Docker Compose
- ключ к языковым моделям, разрешённым условиями кейса (выдаётся организаторами)
- для скриптов аналитики: Python 3.11+, зависимости из `analytics/requirements.txt`

## Запуск

```bash
cp .env.example .env      # указать LLM_API_KEY и LLM_BASE_URL
docker compose up --build
```

Интерфейс: http://localhost:3000

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `LLM_API_KEY` | ключ к языковым моделям; в репозиторий не коммитится |
| `LLM_BASE_URL` | адрес API моделей |
| `ML_URL` | адрес ML-сервиса для бэкенда |

## Пересборка данных

```bash
pip install -r analytics/requirements.txt
python analytics/build_profiles.py --companies <df_Uid_data_hack.csv> \
    --payments <df_Uid_payment_hack.csv> --links <df_Fid_Uid_link_hack.csv>
python analytics/build_matrix.py
python analytics/score_news.py
```

Исходные CSV в репозиторий не входят, их нужно взять из материалов кейса.
