# Альфа-Бизнес

Сайт персональной новостной аналитики находится в [website/](website/). Ветка содержит интерфейс и сервер источников/AI на Node.js; C# API команды находится отдельно в ветке backend.

Доступны персональная лента, сбор публикаций ЦБ, три материала Альфа-Банка из кейса, разбор с точными основаниями, диалог, сравнение компаний, экспорт, серверные отзывы и контроль качества.

## Запуск

Нужны Node.js 24.22.1+, .NET SDK 10 и доступ к репозиторию:

~~~sh
git clone --branch Damir-website --single-branch https://github.com/kam1len58/Alfa-builders.git Alfa-builders-website
git clone --branch backend --single-branch https://github.com/kam1len58/Alfa-builders.git Alfa-builders-backend
cd Alfa-builders-website/website
npx pnpm@11.25.0 install --frozen-lockfile
npm start
~~~

Сайт: http://127.0.0.1:4173. Единый запуск собирает и запускает API; C#-исходники не меняются. BACKEND_PATH задаёт другую папку копии backend. Старые демонстрационные базы сохраняются отдельно по версии схемы.

Для AI скопировать website/.env.example в website/.env.local, указать свой LLM_API_KEY и перезапустить. Без ключа доступны лента, источники и инструменты интерфейса. Ключ в репозитории отсутствует.

## Проверки и документация

Из website/: npm run check и npm test. Тесты используют изолированные синтетические данные; платные запросы не нужны.

- [Запуск, настройки и сценарий проверки](website/README.md)
- [Архитектура и безопасность](website/ARCHITECTURE.md)
- [Метрики и процесс контроля](website/QUALITY.md)

Новостной охват пока ограничен официальным каналом ЦБ, банковский корпус — тремя документами кейса. Даты и исторический характер банковских оценок показаны явно. Проверка цитат и вторая модель не заменяют независимую экспертную оценку.

Исходные XLSX/JSON сохранены в website/data/. Ключи, аккаунты, базы, кэши, журналы и служебные материалы находятся вне Git. Публикация выполняется отдельно по запросу.
