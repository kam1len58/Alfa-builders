# Альфа-Будущее: Бэкенд новостной аналитики и персонализированных инсайтов

Интеллектуальный бэкенд-сервис на .NET 8 для автоматического сопоставления внешних новостей, аналитики Альфа-Банка и детального бизнес-контекста крупных корпоративных клиентов.

## Запуск
Для запуска проекта требуется установленный **.NET 10 SDK**.

```bash
# Перейти в директорию проекта
cd NewsAnalytics

# Запуск бэкенд-сервера
dotnet run --project NewsAnalytics
```

После запуска сервис доступен локально. Интерактивная документация и тестирование API через Swagger UI открываются по адресу:

http://localhost:5194/swagger (порт может отличаться в зависимости от конфигурации окружения).

## Файлы и структура
 - `NewsAnalytics/` — основной проект ASP.NET Core Web API (контроллеры, точка входа Program.cs).

- `NewsAnalytics.DAL/` — слой доступа к данным: Entity Framework Core, контекст базы данных AppDbContext, репозитории и DTO.

- `NewsAnalytics.BLL/` — бизнес-логика: движок скоринга (NewsScorer), сервисы ленты и агентный пайплайн обработки.

- `demo_profiles.json` — исходные профили корпоративных клиентов (выручка, ОКВЭД, регионы, признаки бизнеса).

- `golden_news.json` — эталонный набор новостей с тегами, правилами и экспертной позицией Альфа-Банка (alfa_view).

- `news_analytics.db` — локальная база данных SQLite (создаётся и заполняется автоматически при первом запуске).

## Инициализация и обновление данных
При старте приложения срабатывает автоматический сидер (DbInitializer), который наполняет базу данных из файлов в корне проекта:

- Загружает и валидирует профили компаний из demo_profiles.json.

- Индексирует глобальную базу новостей из golden_news.json.

- Автоматически извлекает экспертные позиции Альфа-Банка из поля alfa_view файла golden_news.json и заполняет таблицу макроаналитики AlfaAnalytics.

- Примечание: Для полного сброса и перезаполнения базы данных достаточно удалить файл news_analytics.db и перезапустить приложение.

## Состав репозитория
Коммитить исходный код бэкенда, конфигурационные файлы, исходные датасеты (demo_profiles.json, golden_news.json), README.md, Docker-конфигурацию и лицензии. Временные файлы сборки (bin/, obj/), локальные базы данных (*.db) и пользовательские файлы окружения в репозиторий не включаются.
